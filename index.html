Wayland-native dwindle & autotiling daemon for Sway, River & wlroots

Rebuilt in C17 and Meson with recursive dwindle layout by default, split size ratios (--mfact), centered master & ultrawide single-window centering, smart gaps, terminal window swallowing, and rich auto-float window rules.

Fedora Linux 45 installation

Install the Fedora 45 toolchain in Step 01, then clone the repository and choose Option A (Meson into /usr/local) or Option B (native RPM into /usr).

01. Install Fedora 45 toolchain, Wayland headers & RPM tools

Installs gcc, meson, ninja, pkgconf, wayland-scanner, wayland-protocols >= 1.36, json-c, and RPM packaging macros.

sudo dnf install -y gcc meson ninja-build pkgconf-pkg-config wayland-devel wayland-protocols-devel json-c-devel rpm-build redhat-rpm-config rpmdevtools gzip tar systemd-rpm-macros

02. Option A: Build and install with Meson (/usr/local)

Standard source build with optional autotiling compatibility symlink.

git clone https://github.com/<your-username>/autotiling-wl.git
cd autotiling-wl
meson setup build --prefix=/usr/local -Dcompat_symlink=true
ninja -C build
sudo ninja -C build install
autotiling-wl --init-config

Quick start & compositor hooks

Initialize ~/.config/autotiling-wl/config once, then launch directly from Sway, River, or a systemd user session.

Sway (~/.config/sway/config)

Starts autotiling in dwindle mode with an optional SIGUSR1 pause/resume keybind.

exec_always autotiling-wl
bindsym $mod+Shift+t exec pkill -USR1 autotiling-wl

River (~/.config/river/init)

Speaks river-layout-v3 natively with dwindle, center-master, and smart gaps.

autotiling-wl --backend river &
riverctl default-layout autotiling-wl

Default configuration (~/.config/autotiling-wl/config)

Generate this file automatically via autotiling-wl --init-config. 

[general]
limit = 0
split_ratio = 1.00
split_ratio_landscape = 1.00
split_ratio_portrait = 0.80
mfact = 0.50
force_split = auto
new_status = slave
single_window_aspect = 16:9
smart_gaps = true
inner_gap = 10
outer_gap = 0
enable_swallow = false
swallow_terminals = foot, alacritty, kitty
split_width = 0
split_height = 0
tabbed_on_min = false

[workspaces]
# 1 = dwindle | 2 = master-stack | 3 = center-master | 4 = tabbed

[float_rules]
rule = app_id:pavucontrol -> float, size 55% 65%, center
rule = app_id:org.gnome.Calculator -> float, center
rule = title:Picture-in-Picture -> float, sticky, size 28% 28%, move 70% 68%

CLI flags reference

Flag Default Description
-l, --limit N0 (dwindle)Cap split depth (0 = recursive dwindle, 2 = master-stack).
-sr, --splitratio R1.00 / 0.80Height/width split threshold; supports --splitratio-portrait for vertical monitors.
--mfact R0.50Master/primary split proportion between 0.10 and 0.90.
--force-split SIDEautoPlace new splits on auto, left (prepend), or right (append).
--new-status MODEslaveKeep newly spawned windows as slave or promote to master.
--single-window-aspect W:H16:9Center solo tiled window on ultrawide displays (0 disables).
--smart-gaps / --inner-gap / --outer-gaptrue / 10 / 0Collapse gaps automatically when <= 1 tiled window or tabbed layout is active.
--swallow / --swallow-term LISTfalse / foot,alacritty,kittyHide launching terminal while child GUI window is open via /proc PPID chain.
--ws-layout WS:MODEdwindleAssign dwindle, master-stack, center-master, or tabbed per workspace.
--float-rule RULE—Match app_id:/title: with -> float, sticky, size W% H%, center, move X% Y%, opacity R, border none.
--tabbed-on-min / -sw / -shfalse / 0 / 0Switch container to tabbed when smaller than min width/height thresholds.
--backend MODEautoSelect auto, sway, river, or wlroots backend driver.
